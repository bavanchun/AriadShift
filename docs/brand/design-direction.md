# Design direction: AriadShift

Outcome: A logo and app icon that read as "transforming a document along a path", never as a "copy/duplicate" icon.
Sub-skills: logo, icon

| Axis | Decision | Why |
| --- | --- | --- |
| Logo style | Combination Mark (mark + wordmark), Flat Duotone | The mark works on its own (app icon, favicon) and next to the wordmark |
| Concept | Ariadne's thread drawn as an **S** (Shift), running from a hollow ring (source) on a plain "raw" sheet to a solid dot (destination) on a dog-eared finished sheet | Name, conversion-router function and direction of transformation live in a single stroke |
| Palette | source `#7A976B`, target `#4A6940`, thread `#FCFBF6`, paper `#F6F4EE`, ink `#232821`, night `#171A16` | Keeps the sage tones of the original sketch; thread/target 5.99:1, thread/source 3.13:1, ink/paper 13.67:1 |
| Typography | Plus Jakarta Sans 700, tracking -0.02em, converted to outline paths | Won a 5-font comparison (Manrope, Outfit, Geist, Onest); OFL license; no font install needed wherever the logo is used |
| Voice | precise, calm, trustworthy | The product handles private documents and favors local processing |

Constraints: Vector-first (SVG master), legible at 16px, works on light and dark backgrounds, has a single-color version.
Non-goals: Multi-layer Liquid Glass icon (Icon Composer `.icon`), a full brand guideline, CIP mockups.
Acceptance criteria:
- The S is recognizable at 32px and still reads as a green shape with a light S at 16px (see `brand/preview.png`).
- The mono version uses no secondary tints and works on any background.
- Every asset is reproducible with `pnpm --dir brand build`.
Brand assets: invented brand — none to locate.

## Assets

All generated by `brand/build.mjs` (design-as-code: SVG geometry → SVGO 4 → resvg 2.6). Provenance: manual composition, no image-generation model.

| File | Use |
| --- | --- |
| `brand/svg/ariadshift-mark.svg` | Color mark, transparent background |
| `brand/svg/ariadshift-mark-mono.svg` | Single-color mark (`currentColor`) |
| `brand/svg/ariadshift-app-icon.svg` | Full-bleed squircle app icon (Windows, Linux, input for `tauri icon`) |
| `brand/svg/ariadshift-app-icon-macos.svg` | macOS app icon with 100px margin and drop shadow |
| `brand/svg/ariadshift-wordmark.svg` | Outlined wordmark |
| `brand/svg/ariadshift-lockup.svg`, `ariadshift-lockup-dark.svg` | Horizontal lockup for light and dark backgrounds |
| `brand/svg/favicon.svg` | Web favicon |
| `brand/png/*` | PNG renders from 16 to 1200px |

After scaffolding Tauri, generate the desktop icon set by running `pnpm tauri icon ../../brand/png/ariadshift-app-icon-1024.png` inside `apps/desktop`.

## Self-critique

| Dimension | Score | Note |
| --- | --- | --- |
| Concept | 8 | S = Shift = guiding thread; swap the brand name and the motif loses its meaning |
| Philosophy alignment | 8 | Consistent flat duotone, no gradients or shadows on the mark |
| Visual hierarchy | 8 | The S is the first read, then the two sheets |
| Craft quality | 7 | Point-symmetric geometry and contrast verified; the ring detail is lost at 16px |
| Functionality | 8 | No superfluous detail; the dog-ear appears only on the target sheet |
| Originality | 7 | Two overlapping sheets are a familiar motif; the thread-drawn S is the distinctive part |
| **Total** | **7.7** | Possible next step: a dedicated favicon without the ring for sizes ≤ 16px |
