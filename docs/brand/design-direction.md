# Design direction: AriadShift

Outcome: A premium, Liquid Glass–era app icon and brand system that reads as "transforming a document along a guided path", never as a "copy/duplicate" icon.
Sub-skills: logo, icon

| Axis | Decision | Why |
| --- | --- | --- |
| Logo style | Combination Mark; the app icon is the primary mark (as Raycast, Arc and Linear do), paired with the wordmark | A rich, dimensional icon carries the brand everywhere: dock, favicon, README, lockup |
| Concept | Ariadne's **golden thread** drawn as an **S** (Shift), running from a hollow ring (source) on a plain "raw" glass sheet to a glossy bead (destination) on a dog-eared finished sheet | Name, conversion-router function and direction of transformation live in a single stroke; gold makes the thread the hero |
| Material | Liquid Glass: frosted sheets that refract what lies behind them, specular top-left rims, darker bottom-right edges for thickness, layered drop shadows, a glass-tube thread with a moving highlight and a dark contour, a lit squircle rim | Matches the macOS 26 / iOS 26 icon language while staying legible at small sizes |
| Palette | Background `#A8CE94 → #4F8C62 → #143A2B` (dark: `#355B44 → #18301F → #070D0A`), glass tint `#F4FFF2`, gold `#FFF1C4 / #F2C063 / #D8912C`, ink `#232821`, paper `#F6F4EE`, night `#171A16`, mono `#2F5B43` | Keeps the sage family of the original sketch, adds depth and a warm accent; ink/paper 13.67:1 |
| Typography | Plus Jakarta Sans 700, tracking -0.02em, converted to outline paths | Won a 5-font comparison (Manrope, Outfit, Geist, Onest); OFL license; no font install needed |
| Voice | precise, calm, trustworthy | The product handles private documents and favors local processing |

Constraints: Vector masters (SVG), legible at 32px and recognizable at 16px, light and dark appearances, a single-color version, native Liquid Glass layers for macOS 26.
Non-goals: Animated icon, full brand guideline book, CIP mockups.
Acceptance criteria:
- The S stays readable in normal vision, a deuteranopia simulation and grayscale; the gold-on-glass hue contrast alone is low (luminance 1.2–2.4:1), so a dark contour around the thread supplies the edge.
- The S is recognizable at 32px (see `brand/preview.png`).
- The mono version uses no secondary tints and works on any background.
- Every asset is reproducible with `pnpm --dir brand build`.
Brand assets: invented brand — none to locate.

## Assets

All generated by `brand/build.mjs` from `brand/src/geometry.mjs` and `brand/src/glass-icon.mjs` (design-as-code: SVG → SVGO 4 → resvg 2.6). Provenance: manual composition, no image-generation model.

| File | Use |
| --- | --- |
| `brand/svg/ariadshift-app-icon.svg` | Primary mark: full-bleed Liquid Glass app icon (Windows, Linux, web, input for `tauri icon`) |
| `brand/svg/ariadshift-app-icon-dark.svg` | Dark appearance |
| `brand/svg/ariadshift-app-icon-macos.svg` | Pre-macOS 26 template: 100px margin and outer shadow |
| `brand/icon-composer/0-background.svg` … `3-thread.svg` | Flat layers for Apple Icon Composer, which applies the native Liquid Glass material |
| `brand/svg/ariadshift-mark-mono.svg` | Single-color mark (`currentColor`) for print, embossing, one-color UI |
| `brand/svg/ariadshift-wordmark.svg` | Outlined wordmark |
| `brand/svg/ariadshift-lockup.svg`, `ariadshift-lockup-dark.svg` | App icon + wordmark for light and dark backgrounds |
| `brand/svg/favicon.svg` | Web favicon |
| `brand/png/*` | PNG renders from 16 to 1200px |

After scaffolding Tauri, generate the desktop icon set by running `pnpm tauri icon ../../brand/png/ariadshift-app-icon-1024.png` inside `apps/desktop`. For macOS 26, import the `brand/icon-composer/` layers into Icon Composer in order (background, source sheet, target sheet, thread) and save the `.icon` file into the app bundle.

## Self-critique

| Dimension | Score | Note |
| --- | --- | --- |
| Concept | 8 | Golden thread = Ariadne = Shift; swap the brand name and the motif loses its meaning |
| Philosophy alignment | 9 | Frosted refraction, specular rims, edge thickness and layered depth follow the Liquid Glass language |
| Visual hierarchy | 9 | The gold S is the first read, glass sheets second, background last |
| Craft quality | 8 | Point-symmetric geometry, true background refraction, contour verified for color-vision deficiency; 16px is a silhouette only |
| Functionality | 8 | Every layer earns its place; the noise texture was dropped because it was invisible and cost 500 KB per PNG |
| Originality | 8 | Two sheets are a familiar motif; the glass-tube golden thread S is distinctive |
| **Total** | **8.3** | Possible next step: hand-tune a 16px favicon in a pixel editor |
