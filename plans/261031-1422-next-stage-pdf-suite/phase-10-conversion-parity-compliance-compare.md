## Compliance

- `pdf.to_pdfa { level: "2b" \| "3b" \| "2u" }`: for IR-family sources, re-render via Typst PDF/A output; for existing PDFs, a conservative fixer in `ariad-pdf` (embed missing fonts where available, add OutputIntent sRGB ICC — bundle a permissive sRGB profile, add XMP PDF/A identification, remove transparency groups only when safe, forbid encryption/JS) **followed by mandatory veraPDF validation**; if validation fails, the tool fails with veraPDF's report (never claims conformance it does not have).
- veraPDF 1.30.3 under its MPL-2.0 option as optional pack `verapdf` (Java runtime bundled from a permissive JDK build — verify; out of process): `pdf.validate_pdfa`, `pdf.validate_pdfua`.
- `pdf.to_pdfua`: tagged PDF from IR via Typst for IR-family sources; existing PDFs get an accessibility report (`pdf.accessibility_report`) rather than a false fix.

## Compare

`pdf.compare { mode: "text" \| "visual" \| "both", pages? }`: text diff using `similar` 3.2.1 (Apache-2.0) over reading-order text per page with word-level changes and page/bbox anchors; visual diff using PDFium renders + `image-compare` (MIT) with highlighted change masks; output JSON + an annotated PDF report (changes highlighted).
