## Resolved findings

- Paragraph defaults overwrote table paragraph values in nested content. The shared resolver now applies defaults, the containing table baseline, named inheritance and direct overrides. HTML, Typst, Pandoc and Rust fidelity observation use it; the matching Python observer and shared vectors preserve parity.
- Rust fidelity observation counted table cell text both through the table and through its children. It now observes caption text at the table and cell text once through the children. The shared table vector checks exact text, its CER denominator and three distinct effective sizes.
- Pandoc omits original DOCX paragraph and run properties from its semantic AST. Bounded recovery from the original package restores matching named/direct paragraph, character and table formatting, preserves explicit false resets, and ignores previous formatting inside tracked-change properties. Host and browser preparation share the implementation.
- Generated DOCX could contain `Table -> TableNormal` without declaring its parent. The writer declares the built-in empty baseline in generated packages. Imported dangling references still fail validation. Real host and memory-package round trips verify effective styles and raw OOXML parent references.
- Styled figure captions and inherited font wrappers around images/whitespace no longer matched the HTML reader's bare-inline checks. The reader now traverses transparent style wrappers and retains the original caption formatting. An independent alt, image title or image highlight still prevents folding that would lose metadata. The CLI test accepts attributes on the figure element and requires an actual Figure after read-back.
- Typst's authored PDF uses an ICC sRGB profile. The PDF reader now recognizes evidenced matrix/TRC sRGB under a bounded decode budget; unknown profiles remain unknown. Tests cover the actual corpus colour and rejected metadata budget consumption.
- Unsupported PDF colour is a style-loss warning, not evidence of missing text. Reusing `StylesDropped` preserves the exact unknown-colour notice while glyph decoding loss and truncated content still make redaction verification unavailable. A real Lab-colour PDF regression checks both absent and present targets; all 27 real PDFium pipeline tests pass. The [independent warning review](../../reports/code-reviewer-261110-1053-color-warning-verification.md) confirms the classification and unchanged publication gates.
- Character-style boundaries changed inspection word counts. Inline counting now carries word state across transparent style spans. The existing PDF word-count snapshots pass unchanged.
- A late job-outputs response could restore a download after job deletion. The component now ignores aborted responses and requires an undeleted successful job before rendering outputs. The existing test deterministically reproduces the original race and retains its focus and removal assertions. The focused account suite and full 308-test web suite pass; the [independent review](../../reports/code-reviewer-261110-1355-job-output-race.md) has no findings.
- Real competitor DOCX used valid text-box stories nested in drawing runs. The local style mapper incorrectly rejected their paragraphs as malformed. It now leaves that unsupported story to Pandoc while retaining the enclosing run state and all XML limits; an explicit `unsupported_node` notice records possible content and formatting loss. Captured official Pandoc output contains only a heading, so neither tests nor scoring claim missing text-box content was recovered. Normal surrounding styles and ordinary trailing text remain required. The [text-box review](../../reports/code-reviewer-261110-1238-docx-textbox-import.md) checks this boundary.
- DOCX image block IDs included temporary extraction paths because mapping finalized identities before media ingestion.
