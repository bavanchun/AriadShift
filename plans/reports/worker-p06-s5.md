# Watermark detection and explicit removal

Status: implementation and review in progress; registry integration is pending.

Detection interprets bounded page and Form streams, tracking matrices, graphics-state alpha, text state and marked content. It reports `ocg`, `artifact`, `annotation`, `repeated_xobject` and `repeated_text` candidates with a page-space bounding box and preview page. The `wm1` identifier contains an encoded detection query and a SHA-256 digest bound to the original input bytes and candidate identity; this allows removal to repeat non-default page and ratio queries and rejects identifiers from another input. Form content is keyed by decoded bytes and subtype, with resource context checked separately so identical programs using different resources are not combined. A bounded reader helper reuses the PDF reader's ToUnicode decoder; undecodable text is keyed by its raw-byte hash.

Explicit watermark markers and watermark annotations score 0.98. Repeated content starts at 0.45, with +0.20 for low alpha, +0.15 for rotation, +0.15 for a central location, +0.20 for a watermark word and +0.05 for large text, capped at 0.99. Opaque, unrotated, noncentral repeated content is capped at 0.60. Corpus kinds and scores are recorded in the three `watermark_detect` snapshots. A 1,000-page local fixture completed detection in 0.34 seconds under a 2 GB process scope.

Removal re-runs each selected query, requires unique explicit candidate IDs, rejects overlaps and applies changes transactionally. It copies selected Form instances and page resources on write, removes only selected operations or annotations, and refuses text or marked blocks if state isolation cannot be proved. AriadShift-origin streams are dropped whole; unused wrapper streams, resources and OCGs are removed only when a bounded reachability and content scan proves that safe. Otherwise the harmless resource or group is retained. Third-party removals emit `third_party_mark`, and the PDF output includes the inline `removed`/`not_selected` report. Host publication of PDF plus JSON remains phase integration work. The brief's encrypted plaintext fixture is replaced by the actual encrypted empty-password fuzz seed.

Focused tests cover corpus removal and body text, deterministic IDs and output, non-default selections, shared forms, own watermark, annotations, foreign/empty/wildcard selections, unsafe text/state, cancellation, page limits, broken xref, cyclic forms and letterhead confidence. PDFium compared the original and restored first page pixel-for-pixel after adding and removing an AriadShift mark. Broader tests, WASM, and independent reviews are in progress.

Focused verification: `cargo test -p ariad-pdf --test watermark_detect --test watermark_remove` passed (16 tests); `cargo test -p ariad-core --lib watermark_` passed (3 tests); the bounded ToUnicode decoder test passed; `cargo clippy -p ariad-core -p ariad-pdf --all-targets -- -D warnings` and `cargo check -p ariad-pdf --target wasm32-unknown-unknown` passed. The PDFium round-trip test passed with `ARIAD_TEST_PDFIUM_DIR` set to the phase pack. These checks do not replace the phase-wide gate.
