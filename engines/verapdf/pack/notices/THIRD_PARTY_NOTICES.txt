AriadShift veraPDF Engine Pack - Third-Party Notices
==================================================

This package contains the veraPDF PDF/A and PDF/UA validation engine.
No Java Runtime Environment (JRE/JDK) is bundled in this pack; execution
uses the user's system Java runtime (JAVA_HOME or java on PATH, Java >= 11).
These components are run strictly out of process as a standalone tool.
